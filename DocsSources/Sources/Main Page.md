# Intro {#mainpage}

CUI is GUI library wrapped as C# mod for Barotrauma  
It can be used by other C#/lua/xml mods to create custom GUI



Shrimplest example:
~~~~~~~~~~~~~{cs}
CUIFrame frame = new CUIDefault.Frame("bruh")
{
  Absolute = new CUINullRect(w: 400, h: 600),
};
~~~~~~~~~~~~~
