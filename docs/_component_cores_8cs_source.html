13 /// <summary>
14 /// Testing Component core concept
15 /// Idea is to put all the logic in cores and make outer component just a wrapper with forwarded prop for the user
16 /// User is not supposed to access the core
17 ///
18 /// Conclusion: dogshit
19 /// 1. There's no way to put components in relations without data duplication or conversion
20 /// 2. No way to double inherit, Links to each other has to be created as new prop and will stack
21 /// 3. this will force all component to be splitted
22 /// </summary>
