All GUI elements:\+ frames, buttons, list, textblock are CUIComponents

They are C\# objects, they all have parameterless constructor so you can just create them

They have props that control how they will be drawn and positioned 
\begin{DoxyCode}{0}
\DoxyCodeLine{CUIFrame\ frame\ =\ \textcolor{keyword}{new}\ CUIFrame()}
\DoxyCodeLine{\{}
\DoxyCodeLine{\ \ Absolute\ =\ \textcolor{keyword}{new}\ CUINullRect(w:\ 400,\ h:\ 600),}
\DoxyCodeLine{\ \ Background\ =\ \{\ Color\ =\ Color.Blue,\ \}\ \textcolor{comment}{//\ you\ can\ set\ deep\ props\ like\ this}}
\DoxyCodeLine{\};}

\end{DoxyCode}
