\doxysubsection{Detailed Description}
Another new half assed library for unit testing

Key class is UTest, it\textquotesingle{}s just a wrapper around expected and real value

UTest\+Pack is a collection of UTest UTest\+Runner is a class for running UTest\+Packs\hypertarget{dir_9cd1d8e27900c8a4332922c888fc7f3f_autotoc_md105}{}\doxysubsubsection{\texorpdfstring{How to use it}{How to use it}}\label{dir_9cd1d8e27900c8a4332922c888fc7f3f_autotoc_md105}
run UTest\+Commands.\+Add\+Commands(); to add {\ttfamily utest} command

Create class derived from UTest\+Pack, add UTest generating methods, Either:\+
\begin{DoxyItemize}
\item override Create\+Tests() and add UTests manually to UTest\+Pack.\+Tests
\end{DoxyItemize}

Or add methods with specific signatures:\+
\begin{DoxyItemize}
\item public UTest Method() should return one UTest
\item public List$<$\+UTest$>$ Method() if you want to return multiple UTests
\item public void Create\+Bla\+Bla\+Bla() Should add tests to UTest\+Pack.\+Tests manually without overriding Create\+Tests
\end{DoxyItemize}

You can derive one UTest\+Pack from another, when you run test pack it also runs all derived packs

Then run utest command with class name ~\newline
 utest command is tabable, without args it prints whole testpack tree

Also you can run test packs manually with UTest\+Runner
